# PAT Colectivo - Control de acceso (Java + MySQL)

Práctica de usuarios, roles y estado de acceso con base de datos MySQL.

## Ejecutar
1. Abrir en GitHub Codespaces (Code > Codespaces > Create codespace).
2. Esperar a que termine setup.sh (instala MySQL, crea la BD y descarga el driver).
3. Abrir `src/Main.java` y presionar Run, o en la terminal: `bash run.sh`
4. Para ver la tabla directo en MySQL: `bash ver_bd.sh`
